# CSEM2151 - Computer Vision

## List of Assignments

#### 1. Performance comparison of MLP, CNN, and Vision Transformer (ViT) using MNIST and CIFAR-10.

#### 2. Comparative study of SRCNN, ESPCN, SRResNet, SRGAN, and EDSR for single-image super-resolution.

#### 3. Image enhancement and restoration using Convolutional Neural Networks (CNNs) and Multi-scale Residual Network (MIRNet).

#### 4. Image generation using Variational Autoencoder (VAE), Denoising Diffusion Probabilistic Model (DDPM), and Latent Diffusion Model (LDM).

#### 5. Peer evaluation and constructive score sheet analysis of course assignments.

#### 6. Image generation, image-to-image translation, inpainting, and outpainting using Stable Diffusion.

#### 7. Artistic style transfer comparison across classical NST, AdaIN, and Stable Diffusion using Jainul Abedin and SM Sultan paintings.

#### 8. Image denoising and learning strategy comparison (direct vs. residual learning) using DAE, RED-Net, U-Net, DnCNN, and custom architectures.

#### 9. CNN operations and performance comparison across regular, 1x1 pointwise, deformable, dilated, and depthwise separable convolution kernels.

#### 10. Semantic image segmentation benchmark comparison across baseline architectures (U-Net, U-Net++, FPN, Attention U-Net, BASNet, DeepLabV3+, SegFormer) and proposed ABR-U-Net on Oxford-IIIT Pet and custom mobile datasets.
